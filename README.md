# AnyDesk Remote Desktop

Fast remote access client built on the DeskRT video codec for responsive desktop control, unattended workstation links, and direct file transfers.

## DeskRT Transport & Unattended Access

| Feature | Behavior |
| --- | --- |
| Address ID | Nine-digit direct routing without port forwarding |
| DeskRT Codec | Sub-16ms local frame delivery over low-bandwidth links |
| Session Permissions | Granular toggles for clipboard, audio, and keyboard lock |

## First Connection Checklist

1. Extract the portable archive and run `AnyDesk.exe`.
2. Share your 9-digit Address ID or configure an unattended access password.
3. Adjust display quality and privacy mode from the active session toolbar.
